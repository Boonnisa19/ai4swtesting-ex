### Test Ideas – Password Validation

| ID    | Test Idea                                                                                                              | Expected Result                                 |
| ----- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| TI-01 | Verify that a password with exactly 8 characters, including at least one digit and one uppercase letter, is accepted.  | Password is accepted.                           |

- Minimum and maximum length boundaries
